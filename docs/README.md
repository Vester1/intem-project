# Документация прототипа КП2

[Описание проекта и команды запуска](../README.md) находятся в корневом README прототипа.

| Файл | Содержание |
|---|---|
| [SYSTEM_EXPLANATION.md](SYSTEM_EXPLANATION.md) | Полное объяснение системы и технологий из обсуждения: цель КП2, архитектура, маршруты, агенты, RAG, поиск, векторы, модель, API, ограничения и формулировка для защиты |
| [OWNERSHIP.md](OWNERSHIP.md) | Распределение ответственности пяти участников и состояние их компонентов |
| [graph.mmd](graph.mmd) | Граф, выгруженный из LangGraph, в формате Mermaid |
| [demo-routing.json](demo-routing.json) | Примеры маршрутов ответа и отказа, полученные при запуске без LLM |

Для изучения проекта начни с `SYSTEM_EXPLANATION.md`, затем открой граф и код соответствующих агентов. Техническая проверка цитат в КП2 не является независимой смысловой проверкой ответа.
